## 🧭 رؤية ومنهجية الكورس (The Engineering Philosophy)
الهدف الأساسي هو كسر النمط التقليدي للتعلم القائم على المشاهدة السلبية للدورات ("Tutorial Hell") وتطبيق مبدأ **(Zero-Fluff / Production-First)**:
1. **التعلم عبر البناء الحقيقي:** دراسة أي تقنية تبدأ بحل مشكلة برمجية واقعية داخل الكود مباشرة.
2. **التطور المعماري التراكمي:** بناء نظام إدارة مبيعات وأقساط المتاجر، والارتقاء به يومياً من صفحة محلية بسيطة إلى نظام سحابي متزامن ومدعوم بالذكاء الاصطناعي.
3. **التوثيق الهندسي المستمر:** توثيق كل خطوة وأمر برمجي وخلفيته العلمية ليكون هذا المستودع مرجعاً تقنياً وبورتفوليو احترافي يُعرض لأصحاب العمل والشركات.

## 🗺️ خطة الكورس التفصيلية الكاملة (Complete Course Curriculum)

تم تقسيم رحلة البناء إلى 6 محطات هندسية متتالية تمهد للانطلاق بالمشروع الإنتاجي التجاري الضخم:

### 📍 اليوم الأول: هندسة الواجهات التفاعلية وتأسيس المنطق الرياضي (Frontend Foundations)
* **المحاور النظرية والعملية:** معمارية الويب، شجرة الـ DOM، تصميم الواجهات المظلمة (Dark Mode UI)، المتغيرات اللونية، وربط الواجهة بالمحركات الحسابية.
* **المخرجات:** بناء تطبيق حاسبة الأقساط والمبيعات وتشغيله محلياً عبر Live Server بدون أخطاء حسابية.

### 📍 اليوم الثاني: معمارية التخزين، التحكم بالإصدارات، والنشر الحي (Storage & Deployment)
* **المحاور النظرية والعملية:** الفرق بين الذاكرة المؤقتة (RAM) والتخزين الدائم (`localStorage`)، تسلسل البيانات النصية عبر JSON، إعداد نظام Git عالمياً، وحل مشاكل الـ CLI، وتفعيل خطوط النشر التلقائي عبر GitHub Pages.
* **المخرجات:** إطلاق الإصدار 2.0 من التطبيق ونشره برابط عام دائم على الإنترنت ومشاركته للاستخدام المباشر.

### 📍 اليوم الثالث: قواعد البيانات السحابية والمزامنة اللحظية (Cloud Database & Real-Time Sync)
* **المحاور المستهدفة:** الانتقال من التخزين الأحادي المعزول لكل جهاز إلى التخزين المركزي، إنشاء قاعدة بيانات PostgreSQL عبر منصة **Supabase**، كتابة استعلامات الجلب والتحديث، وتزامن البيانات فورياً بين الهاتف والحاسوب.
* **المخرجات:** وصولات المبيعات والأقساط التي تُسجل بالموبايل تظهر في نفس الثانية على شاشة الحاسوب.

### 📍 اليوم الرابع: حقن نماذج الذكاء الاصطناعي والأتمتة الذكية (Generative AI Integration)
* **المحاور المستهدفة:** معمارية الـ REST APIs، الاتصال بنماذج الذكاء الاصطناعي (AI APIs)، صياغة الأوامر الهندسية الموجهة (Prompt Engineering)، تحليل سلوك التسديد المالي للزبون، وتوليد مطالبات دفع ذكية وتلقائية عبر WhatsApp.
* **المخرجات:** تحويل التطبيق من مجرد أداة حسابات إلى مستشار مالي ذكي يتخذ قرارات وينبه صاحب العمل.

### 📍 اليوم الخامس: الأمان ومعمارية الأنظمة المتقدمة (Security & PWA Architecture)
* **المحاور المستهدفة:** تشفير وتأمين مفاتيح الاتصال البرمجية (API Keys & Security Rules)، تحويل الموقع إلى تطبيق ويب تقدمي (**PWA**) يمكن تثبيته كأيقونة على شاشات الهواتف للعمل دون الحاجة لمتصفح.
* **المخرجات:** تطبيق قابل للتثبيت على الهواتف والأجهزة مع حماية أمنية للبيانات.

### 📍 اليوم السادس: التحضير للمشروع الضخم والانطلاق التجاري (Production Blueprint)
* **المحاور المستهدفة:** مراجعة الكود البرمجي (Refactoring)، وضع مخطط قاعدة البيانات العلائقية (Relational Schema) للمشروع النهائي، وجدولة ميزات إدارة المخازن والجرد، والطباعة الحرارية، وتعدد العملات (دينار / دولار).
* **المخرجات:** مستند التأسيس المعماري للمشروع التجاري الفعلي بعد تخرج الطالب من الكورس العملي.

### 🔹 اليوم الأول: تأسيس الواجهة ومنطق الاحتساب الرياضي (Prototype v1.0)
* **تاريخ الإنجاز:** 2026-11-07
* **حالة الإنجاز:** مكتمل بنسبة 100% ✅

#### 1. الشرح الهندسي والمفاهيم المتقنة:
* **بيئة التطوير (Developer Environment):** ضبط محرر VS Code، وتفعيل إضافة **Live Server** التي تعمل كخادم ويب محلي (`Localhost Port 5500`) يرصد التعديلات اللحظية في ملفات المشروع ويعيد تحميل الصفحة تلقائياً مع كل عملية حفظ (`Ctrl + S`).
* **شجرة عناصر الصفحة (The DOM Tree):** فهم آلية ترجمة المتصفح لكود الـ HTML إلى كائنات برمجية قابلة للوصول والتعديل بالـ JavaScript عبر دوال الاستهداف مثل `document.getElementById()`.
* **هندسة التصميم العصري (Modern CSS & Variables):** 
  * تصميم واجهة مريحة ومظلمة (Dark Theme) لتخفيف إجهاد العين وتقليل استهلاك البطارية.
  * استخدام نظام المتغيرات اللونية في الجذر (`:root CSS Variables`) لتسهيل توحيد وتغيير الألوان العامة بمرونة عالية.
  * الاعتماد على نظام **Flexbox** لجعل الواجهة مرنة ومتوافقة تماماً مع شاشات الهواتف الذكية.
* **المعالجة الرياضية (Arithmetic Logic Engine):** بناء دوال JavaScript تأخذ مدخلات السعر الكلي، المقدمة، ومدة السداد، وتجري العمليات الحسابية التالية بدقة:
  $$\text{المتبقي} = \text{السعر الكلي} - \text{المقدمة}$$
  $$\text{القسط الشهري} = \frac{\text{المتبقي}}{\text{عدد الأشهر}}$$

#### 2. المخرجات والنتائج:
* واجهة سريعة، تفاعلية، تعمل بنعومة وبدون أي مكتبات أو أطر عمل ثقيلة (Vanilla JS/CSS).
* نموذج أولي يثبت صحة المنطق البرمجي لحساب الأقساط.

### 🔹 اليوم الثاني: هندسة التخزين المحلي، إدارة النسخ بـ Git، والنشر العالمي (Deployment v2.0)
* **تاريخ الإنجاز:** 2026-11-08
* **حالة الإنجاز:** مكتمل بنسبة 100% ✅

#### 1. الشرح الهندسي والمفاهيم المتقنة بالتفصيل الدقيق:

* **معمارية التخزين: الـ RAM مقابل الـ `localStorage`:**
  * **الذاكرة المؤقتة (RAM):** تم استيعاب أن مربعات الإدخال (`<input>`) تعيش فقط في الـ RAM أثناء عمل جلسة المتصفح. بمجرد الضغط على زر التحديث (**Refresh**)، يقوم المتصفح بمسح الذاكرة بالكامل وبناء الصفحة من الصفر.
  * **الذاكرة الدائمة (`localStorage`):** خزانة محلية دائمة يقدمها المتصفح بسعة تصل إلى (5MB - 10MB). تم ربط عملية الخزن بضغطة زر مخصصة، لضمان عدم حفظ السجلات إلا بعد اعتمادها من قبل المستخدم.

* **تسلسل البيانات النصية (Serialization & JSON Transformation):**
  * المتصفحات لا تسمح بتخزين مصفوفات الكائنات البرمجية المباشرة (Arrays of Objects) داخل الـ `localStorage`.
  * **التسلسل (Serialization):** تم استخدام دالة `JSON.stringify()` لتحويل جدول وسجلات الوصولات إلى سلسلة نصية صريحة قابلة للتخزين كـ (Key-Value).
  * **إعادة التفكيك (Deserialization):** تم استخدام دالة `JSON.parse()` عند بدء تشغيل التطبيق لإعادة قراءة النص وتحويله مجدداً لمصفوفة تفاعلية وعرضها في السجل.

* **التفاعل مع نظام التشغيل (System Clipboard Integration):**
  * بناء وظيفة نسخ رسالة الحسابات مباشرة عبر الواجهة البرمجية `navigator.clipboard.writeText`.
  * صياغة تقرير الواتساب باستخدام مصفوفات النصوص الديناميكية (**Template Literals**) باستخدام الرموز (`` ` ``) لدمج المتغيرات المالية في قالب رسالة احترافية قابلة للإرسال الفوري للزبون.

* **نظام إدارة النسخ (Git Version Control):**
  * تنصيب أداة Git وربطها بالـ Terminal في VS Code.
  * إعداد الهوية البرمجية العالمية للمطور:
    ```bash
    git config --global user.name "Abood"
    git config --global user.email "engabdullah3d@gmail.com"
    ```
  * تشخيص وحل خطأ `CommandNotFoundException` الناتج عن عدم تحديث مسارات بيئة النظام (`System PATH`)، وتم التغلب عليه عبر إعادة تشغيل المحرر.
  * استيعاب مراحل انتقال الكود الأربعة:
    1. **Working Directory:** كتابة الكود داخل المحرر.
    2. **Staging Area:** تجهيز الملفات عبر `git add`.
    3. **Local Commit:** أخذ لقطة حفظ مشفرة بتاريخ ووصف محدد.
    4. **Remote Push:** رفع التعديلات نحو السحابة على مستودع GitHub.
  * فهم سبب ظهور ملف `COMMIT_EDITMSG`، وهو آلية الحماية التي يفرضها Git لإجبار المطور على كتابة رسالة توثيقية واضحة تصف ما تم تعديله.

* **الاستضافة والنشر السحابي (GitHub Pages Deployment):**
  * رفع مستودع المشروع العام باسم: `AI-Mastery-App`.
  * ضبط إعدادات النشر المباشر (GitHub Pages) وربطه بالفرع الرئيسي المباشر (`main`).
  * حل إشكالية عدم تزامن البيانات بين الهاتف والحاسوب، وإدراك المفهوم المعماري بأن الواجهات السحابية الحالية (Static Frontend) تحتاج بالضرورة لخادم أو قاعدة بيانات سحابية مركزية (Backend Database) لتحقيق المزامنة المتعددة.
