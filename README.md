## 🧭 رؤية الكورس ومنهجية العمل (The Philosophy)
الانتقال من مرحلة المتلقي التقليدي للدورات النظرية المطولة ("Tutorial Hell") إلى **عقلية المهندس المبتكر (Zero-Fluff / Production-First)**:
* **التطبيق الحي الفوري:** كل مفهوم نظري يتم تحويله بلحظتها إلى كود يعمل داخل المتصفح.
* **البناء التراكمي للمشاريع:** البدء بحل مشكلة سوقية حقيقية (أداة إدارة مبيعات وأقساط المتاجر الذكية) وتطويرها خطوة بخطوة من واجهة محلية معزولة إلى تطبيق سحابي كامل مدعوم بالذكاء الاصطناعي.
* **الاعتماد على بيئات العمل الاحترافية:** استخدام محرر VS Code، وإدارة الإصدارات عبر Git، والنشر الحي عبر سحابة GitHub.

### 🔹 اليوم الثاني: هندسة التخزين، Git، والنشر الحي (Production & Deployment)
* **تاريخ الإنجاز:** 2026-11-08
* **الهدف:** تطوير التطبيق إلى الإصدار 2.0، حل مشاكل فقدان البيانات بالرفرش، التحكم بالإصدارات، ونشر المشروع للعالم برابط حي.

#### 1. ما تم تعلمه بالتفصيل الدقيق:
* **هندسة التخزين المحلي (`localStorage` vs RAM):**
  * **الـ RAM (الذاكرة المؤقتة):** تستقبل مدخلات حقول النص فقط أثناء تشغيل الصفحة وتفرغها تلقائياً عند إعادة التحميل (Refresh).
  * **الـ `localStorage`:** خزنة داخل متصفح الجهاز تخزن البيانات بدون تاريخ انتهاء.
  * **التسلسل النصي (Serialization):** استخدام `JSON.stringify()` لتحويل مصفوفات وسجلات الوصولات إلى نصوص يتم حفظها، واستخدام `JSON.parse()` لإعادة تفكيكها لقوائم برمجية عند إعادة فتح التطبيق.
* **أداة التحكم بالإصدارات (Git Version Control):**
  * تنصيب Git وتهيئة الهوية البرمجية من الـ Terminal بأوامر الحساب الشاملة:
    ```bash
    git config --global user.name "Abood"
    git config --global user.email "engabdullah26ai@gmail.com"
    ```
  * تشخيص وحل خطأ `CommandNotFoundException` بإعادة تشغيل بيئة المحرر لتحديث مسارات النظام (PATH).
  * فهم دورة حياة الملفات البرمجية: من الملف المعدل (`Working`) إلى منطقة التجهيز (`Staged`)، ثم لقطة الحفظ (`Commit`)، وصولاً للرفع السحابي (`Remote Push`).
* **الاستضافة السحابية المباشرة (GitHub Pages):**
  * ربط VS Code بحساب GitHub ورفع مستودع المشروع العام باسم `AI-Mastery-App`.
  * تفعيل استضافة صفحات GitHub عبر فرع الإنتاج الرئيسي (`main`).

#### 2. النتائج والمخرجات الحية:
* **إطلاق الإصدار 2.0 من التطبيق:** دعم توليد وصولات الحسابات تلقائياً، نسخ تقرير الواتساب بضغطة زر واحدة عبر كليب بورد المتصفح، وسجل محفوظات لا يضيع بعد إغلاق المتصفح.
* **الرابط الحي المنشور على الإنترنت:** 
  🔗 [https://engabdullah26ai.github.io/AI-Mastery-App/](https://engabdullah26ai.github.io/AI-Mastery-App/)
* **الفهم المعماري للـ Frontend والـ Backend:** إدراك السبب الهندسي وراء بقاء البيانات محلية داخل كل جهاز وعدم انتقالها بين الموبايل والحاسبة إلا عبر خادم سحابي مركزي (Cloud Database).
